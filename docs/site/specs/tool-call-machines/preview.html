The machine on a tool call

What landed. Web rows use the client's real stylesheet, fonts, icons, and row markup. The TUI is drawn from its theme and header layout. The session attaches yunhao-labserver, yunhao-labpc, and unicorn, and their colours are the ones the real hash gives them.

Web, full mode

Every row that ran on a machine says which. Global tools and transfer stay bare. Buttons on a running or waiting row push its label left until the call ends.

Web, reduced mode

The default mode. The live row names the machine of the running call, and the folded row lists the machines it touched.

Approval card

Before you allow a command, the card says where it will run.

Subagent row

The row names where the subagent works, unless that is the only machine its parent is on. Web only: the TUI has no subagent row.

Phone

The shared prefix drops, so yunhao-labpc reads labpc. The label keeps its room and the command cuts first. Unicorn shares no prefix and stays whole.

TUI

The same column at 120 columns, shortened at 60. Follows the theme switch above.

Share-link guests

A guest sees the same labels. They read them from a session-level runtime list, so nothing extra is recorded on tool calls.

When it shows

Two or more machines, counting those attached and those in the session's past calls. Two runtimes on one computer count once, and the machine hosting an ACP agent counts as attached.
