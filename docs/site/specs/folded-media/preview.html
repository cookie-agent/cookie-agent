Media the agent saw, in folded work

2026-11-26 · draft for docs/site/specs/folded-media.md · a hand-made mock-up; pictures are drawn by the page

Web: a finished reply

The folded row counts what the agent saw and shows it as a strip. Click a thumbnail: the viewer steps through the strip, and Show call opens the fold at the call that returned it. Click the row itself to open the fold, where the strip hides because every call shows its own media.

Left: desktop. Right: a phone, where the strip scrolls sideways. The fourth picture carries the "not shown to the model" mark (the model took no images in tool results).

Web: while the agent works

Thumbnails rise in as calls return them, under the two live lines. Once the strip is full, older ones slide into the +N tile so the row never grows.

TUI

Text only: one line of names under the row. Each name opens that picture in the web page; ↗ open opens the first. A ° marks a picture the model never saw.

Sealed row above, live row below (the names line updates in place; a new name draws dim for one step).

What counts

  • Pictures and videos in a tool call's Media blocks: read, read_artifact, MCP tools, an ACP agent's own Read. Not PDFs or audio, not the user's attachments, not <attach/> cards (they never fold).
  • Failed calls add nothing. The same picture read twice shows once. Order is call order; one run's fold lists the whole run.
