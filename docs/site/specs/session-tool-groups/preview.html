Tool groups and skills in the web client: draft

No separate tools panel and no rule editor: every choice is one group or one skill, set to On, Deferred, or Off (skills: on or off). Tool groups sit on the runtime that brings them, in the session panel's Runtimes tab, on the New session page's cards, and in the project editor's cards. Skills get a tab and a section of their own.
